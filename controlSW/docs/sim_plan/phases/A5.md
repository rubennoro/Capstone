# A5: Franka Hand: hand_logic, non-blocking FrankaHandDriver, hand_server (real + fake), HandSim on the A4 tendon hook (Track A, wave W6)

## Goal

The controller drives a Franka Hand through one driver whose code is identical in sim and on hardware. Only the endpoint differs:
- **sim:** the bridge serves `hand_cmd` / `hand_state` through `MuJoCoBackend.extra_topics`, with libfranka move/grasp semantics on the finger tendon (replaces A4's PD finger hold);
- **hardware:** `hand_server` (port 5566) runs the blocking libfranka `Gripper` calls in its own process.

Why non-blocking: `FrankaCartesian` calls `gripper.get_width()` at 200 Hz (`read_robot_state`) and `gripper.set_width()` at 50 Hz inside its control loop (`controllers/franka_cartesian.py:131,156-158`). libfranka `Gripper.move/grasp` block for 0.3–1.5 s.

## Units and config

- **Width map:** `train = a·gap + b` (training units, metres), `gap = clip((w − b)/a, gap_min_m, gap_max_m)`. The Hand gap = `finger_joint1 + finger_joint2` = 2 × the `split` tendon length (0–0.080 m).
- **The driver's config is the merged `ctrl["gripper"]`** (`launch/launcher.py` `build_controller_cfg`: franka_cartesian.yaml < `station.controller_fragment()` < deploy override). It has keys:
  - `type: franka_hand`, `endpoint`, `width_map {a, b, gap_min_m, gap_max_m}`;
  - `speed_m_s`, `force_n`, `force_max_n`, `grasp_epsilon_inner_m`, `grasp_epsilon_outer_m`;
  - the servo leftovers from the file (`calibration`, `squeeze_*`, `current_limit`), which must be **ignored**;
  - optional `policy: {close_below_train_m, open_above_train_m, move_deadband_m, min_cmd_interval_s}`, else the `HandPolicyConfig` defaults.
- **Never hardcode tooling values** (finger extension, camera side, width map, force, epsilons). Read them from the station or the config. The +10 cm / −y design is still a placeholder in the YAMLs: tests run at the station value **and** at `--set tooling.finger_adapter.extension_m=0.1 tooling.tcp_x_along_hand=-y`.

## hand_logic.py (pure)

```python
@dataclass
class WidthMap: a=1.0; b=0.008; gap_min_m=0.0; gap_max_m=0.08
    def gap(self, w_train) -> float; def train(self, gap) -> float; @classmethod def from_config(cls, d)
@dataclass
class HandCmd: kind: str; width_m: float; speed_m_s: float; force_n: float = 0.0; eps_inner_m: float = 0.0; eps_outer_m: float = 0.0
    def to_msg(self, seq) -> dict           # the I-HAND hand_cmd dict
@dataclass
class HandPolicyConfig: close_below_train_m=0.06; open_above_train_m=0.066; move_deadband_m=0.004; min_cmd_interval_s=0.25;
                        speed_m_s=0.1; force_n=30.0; force_max_n=70.0; eps_inner_m=0.01; eps_outer_m=0.08
class HandCommandPolicy:
    def __init__(self, cfg: HandPolicyConfig, wm: WidthMap); state: "OPEN" | "GRASPING"
    def update(self, w_train: float, now: float, hand_state: dict | None) -> HandCmd | None
```

- **OPEN**, and `w < close_below` → `grasp(width = gap(w), force, eps)`, enter GRASPING. The grasp is not rate-limited.
- **OPEN**, `|gap(w) − last_sent| > deadband`, `min_cmd_interval_s` elapsed and the hand is not busy → `move(gap(w))`.
- **GRASPING**, and `w > open_above` → `move(gap(w))`, enter OPEN.
- **Limits:** `force_n ≤ force_max_n` (≤ 70 N); `speed_m_s ≤ 0.1`; width clipped to the gap range (count clips).
- No numpy-free requirement, but no zmq, mujoco or robotmq imports: the module must import in BP.

## FrankaHandDriver (`gripper/franka_hand.py`)

```python
class FrankaHandDriver(GripperDriver):
    def __init__(self, endpoint, width_map: WidthMap, policy: HandPolicyConfig, rate_hz=50.0, rpc_timeout_s=0.1, stale_s=0.2)
    def set_width(self, width_m)      # stores the latest training width; never blocks (no I/O)
    def commanded_width(self)         # the policy width (no squeeze offset: the Hand grasps with force)
    def get_width(self)               # cached train(gap); stale > stale_s -> the last value, stale_reads += 1
    def target_position(self)         # train(width of the last sent cmd); with the identity cal the controller trace's
                                      # width_servo_target = the hand's target in training units
    def status(self) -> dict          # cmds_sent, rpc_timeouts, stale_reads, clips, last_result, grasped, mode, policy state
    def close(self)
```

- **`cal`:** an identity `WidthCalibration([0, 0.2], [0, 0.2])` passed to `GripperDriver.__init__` with `squeeze_delta_m=0`. Existing `.cal` users (`trace_extra`) keep working.
- **Background thread** with its **own** `BridgeClient(endpoint, timeout_s=rpc_timeout_s)` (lazy pirate; created in the thread). Each period (1/rate_hz):
  1. `hand_state`;
  2. `policy.update(latest w, now, state)`;
  3. if a cmd results, `hand_cmd` with an increasing `seq`.
  - Timeouts are counted, never raised into the controller.
- **`make_gripper(cfg)`:** `type == "franka_hand"` → `from franka_deploy.gripper.franka_hand import FrankaHandDriver` (lazy) → `FrankaHandDriver.from_config(cfg)`. This must come before `WidthCalibration.from_config(cfg["calibration"])`, so a config without `calibration` also works. The other kinds are unchanged.

## hand_server.py (port 5566)

`python -m franka_deploy.gripper.hand_server --endpoint E --backend fake|libfranka [--hostname H] [--object-width-m W] [--cmd-latency-s S] [--no-homing]`

- **Socket:** `BridgeServerSocket` on E, normalised for bind (`localhost` → `127.0.0.1`: the launcher passes `tcp://localhost:5566`). Topics `hand_cmd`, `hand_state`; unknown → `ok: false`. The REP loop never blocks on the hand.
- **`FakeHand`:** kinematic gap at the commanded speed. It stalls at `--object-width-m` while closing (grasp → holding, grasped by the epsilons; move → `move_failed`). `--cmd-latency-s` simulates libfranka's blocking time, so the tests can prove the driver never waits.
- **`LibfrankaHand`** (`# pragma: no cover`):
  - one worker thread runs `panda_py.libfranka.Gripper(hostname)` `homing()` (at start unless `--no-homing`), `move(width, speed)` and `grasp(width, speed, force, epsilon_inner, epsilon_outer)`;
  - a state thread polls `read_once()` (width, is_grasped); `gap_vel_m_s` is computed by finite difference;
  - a new command while busy calls `stop()` from the REP thread first, then queues the new one (latest wins).
- **`hand_state`:** `{gap_m, gap_vel_m_s, busy, mode, grasped, last_result, seq_done, t}`, with `t = time.monotonic()` of the last read.
  - `mode`: idle | moving | grasping | holding | homing | stopped | error.
  - `last_result`: move_ok | move_failed | grasp_ok | grasp_failed | stopped | homing_ok | error:…

## HandSim (`franka_sim/hand_sim.py`) + MuJoCoBackend

```python
class HandSim:
    def __init__(self, core: SimCore, tooling: dict, kp=HAND_KP, kd=HAND_KD)
    def command(self, msg: dict) -> dict      # thread-safe (own lock); stores the pending cmd; applied at the next control step
    def ctrl(self, core) -> float             # the A4 hook: tendon force for this control step, clipped to ±limits["hand_force_max_n"]
    def state(self, t_mono: float) -> dict    # the I-HAND hand_state dict
```

The tendon length is gap/2. The tendon force splits 0.5/0.5 onto the two finger joints, so **a squeeze of F N per finger = tendon force −2F** (mark this verify-on-hardware).

- **`move(width, speed)`:**
  - the reference ramps at `speed` (gap rate);
  - capped PD on the tendon length (A4 gains as defaults);
  - done → `move_ok` when |error| < 1 mm;
  - blocked (error > 2 mm for > 0.2 s) → `move_failed`, hold where it is.
- **`grasp(width, speed, force, eps_i, eps_o)`:**
  - close at `speed` toward `max(0, width − eps_i)`;
  - contact = stall (|gap_vel| < 2 mm/s for 50 ms with error > 1 mm) → mode `holding`, tendon force −2·force;
  - `grasped` = `width − eps_i ≤ gap ≤ width + eps_o`, updated every step while holding (a slipped object clears it);
  - reaching the target without a stall → `grasp_failed`, position hold.
- **`stop`:** position hold at the current gap, `stopped`. **`homing`:** move to `gap_max_m`, then `homing_ok`.
- **`MuJoCoBackend`:**
  - builds a `HandSim` and sets `core.hand_ctrl = hand.ctrl` (the A4 PD hold stays as the fallback when no HandSim is installed);
  - `extra_topics = ("hand_cmd", "hand_state")`; A6 appends `sim_*`;
  - `handle_extra("hand_cmd")` returns `{accepted, seq}` without taking `_core_lock`. `handle_extra("hand_state")` returns the hand snapshot, which the loop updates with the arm snapshot.
  - **Do not add hand keys to `get_state`** (its key set = FakeBackend's + `sim_t`, A4 review).
- The arm is under-damped (ζ_eff ≈ 0.35–0.47, 15–34 % step overshoot; A4 review). Do not retune it in A5. Tests that lift after a grasp must allow ≥ 1.5 s to settle.
- **A4 reflexes run only in `running` / `moving`.** A grasp while the arm is idle cannot trip a reflex; the stack test runs with the arm running.
