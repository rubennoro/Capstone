## Findings
1. **LOW: model.py:265, half-pixel principal-point offset.** The render sits about 0.5 px left of and above the OpenCV pinhole projection on both axes, consistent across 4 points. The WORKLOG claims "< 0.1 px".
   - Cause: MuJoCo measures from the continuous image centre W/2, while OpenCV puts pixel centres at integer coordinates.
   - Fix: `principal_pixel = [W/2 - (cx+0.5), (cy+0.5) - H/2]`, or document the convention.
   - Impact is negligible (0.04°) for the policy, but A7/rendering checks with tight pixel tolerances should know about it.
2. **INFO: model.py:382.** Spec 4.4 says to use the station F_T_TCP when it is "non-placeholder". The code also excludes `hw` status. This is defensible (`hw` = not yet measured), but it is an unstated tightening; record it in the report.
