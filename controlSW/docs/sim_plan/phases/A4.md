## SimCore

```python
class SimCore:
    def __init__(self, sm: SimModel, cfg: dict, q_init): ...
    def set_target(self, O_T_EE): ...; def start(self); def stop(self); def recover(self); def inject_reflex(self, msg)
    def begin_joint_move(self, q_goal, speed) -> float; def step(self, n: int = 1); def state(self) -> dict
    # state(): O_T_EE (4x4), q, dq, O_F_ext (6), tau_ext (7), mode, error (str|None), sim_t, success_rate=1.0
```

**Control law** (each 1 ms control step; `substeps` mj_steps per control step from physics.yaml):
1. Target filter: `p_d ← fc·p_t + (1−fc)·p_d`, quaternion slerp with fc. fc = `impedance.filter_coeff`; at 1.0 there is no filtering.
2. Errors: position e_p = p − p_d. Orientation: if q·q_d < 0, flip q_d; `e_q = q⁻¹·q_d`; `e_r = −R·vec(e_q)`.
3. τ_task = Jᵀ(−K·e − D·J·dq), where K = diag(translational×3, rotational×3), D = 2·ζ·√K, J = the 6×7 Jacobian of the EE site (O frame).
4. τ_ns = (I − Jᵀ·J⁺ᵀ)·(k_ns·(q_ns − q) − 2√k_ns·dq), with `q_ns` = q at `start()`.
5. τ_d = τ_task + τ_ns + Coriolis (`qfrc_bias` minus gravity; compute gravity separately with zero velocity).
6. Rate limit: |τ_d − τ_prev| ≤ 1 Nm per ms. Saturate to ±`tau_max_nm`.
7. Applied to MuJoCo: `ctrl = τ_d + gravity(q, m_configured)`. The robot compensates gravity for the payload it was told about. The real payload mass lives in the model; `physics.payload_error_kg` adds a mismatch (J_comᵀ·Δm·g) so a wrong Desk payload shows up as steady-state error.

**Modes:**
- `idle` / `stopped`: joint PD hold at the q captured on entry (stiff), with no Cartesian control.
- `running`: impedance.
- `reflex`: freeze (joint PD hold); `set_target` is ignored until `recover()`.
- `begin_joint_move`: a quintic trajectory over a duration set by speed × dq_max, joint PD tracking; `start()` is refused during it.

**Reflexes** (checked every control step; the first hit sets `error` (str) and `mode = "reflex"`):
- `cartesian_reflex`: |O_F_ext_j| > force threshold.
- `joint_reflex`: |τ_ext,i| > torque threshold.
  - τ_ext = the arm-DOF part of `qfrc_constraint`, plus `qfrc_applied`, plus any xfrc applied.
  - O_F_ext = pinv(Jᵀ)·τ_ext.
  - Thresholds from `robot.impedance.collision_thresholds`, else libfranka defaults: τ [20,20,18,18,16,14,12] Nm and F [20,20,20,25,25,25].
- `joint_position_limits_violation`: q outside the MJCF range minus 0.
- `joint_velocity_violation`: |dq| > `dq_max`.
- `self_collision_avoidance_violation`: any self contact (arm/hand/tooling pairs, as in kinematics "self" + "tooling").
- Optional, off by default, per `physics.reflex`: `controller_torque_discontinuity`, Cartesian speed.

## MuJoCoBackend

```python
class MuJoCoBackend(Backend):
    @classmethod
    def from_config(cls, backend_cfg: dict, home_O_T_EE) -> "MuJoCoBackend"
    extra_topics: tuple = ()          # A5/A6 add hand_*/sim_*
    def handle_extra(self, topic, data)
    # start/set_target/get_state/move_joints/stop/recover/inject_reflex/loop_stats/close as Backend
```

- **`backend_cfg` keys** (`backend.mujoco` in bridge.yaml):
  - `station` (a deploy-style spec of ids or a path to `station_resolved.yaml`), `robot`, `rate_hz` (1000), `q_init` (null → IK of `home_O_T_EE` near home_q);
  - `max_catchup_steps` (10), physics overrides, `viewer: false`;
  - impedance/collision from `backend.panda_py` (the same dict the real arm gets) with `backend.mujoco` overrides.
- **Thread loop:**
  - `t0 = monotonic`; each wake, `due = floor((now − t0)·rate) − k_done`;
  - step `min(due, max_catchup_steps)` control steps;
  - more than 50 ms behind → resync (`rt_resyncs += 1`);
  - after stepping, update a cached state snapshot under `_lock`.
- **`get_state`:** the cached snapshot (no MuJoCo calls); keys exactly as FakeBackend, plus `sim_t`. `O_T_EE` = the `ee` site pose.
- **`move_joints(q, speed)`** blocks until the joint move completes, mirroring PandaPyBackend (stop, then move, then the caller restarts).
- **`loop_stats`:** the FakeBackend fields (periods; `cycle_hist` of compute time) plus `sim_lag_ms_max`, `steps_per_wake_max`, `rt_resyncs`, `realtime_factor`.
- **`close()`:** stop the thread; close the viewer if any.

## franka_deploy integration (additive)

- **`make_backend`:** `kind == "mujoco"` → `from franka_sim.backend import MuJoCoBackend` (lazy) → `MuJoCoBackend.from_config(cfg, home_O_T_EE)`. A clear error when franka_sim or mujoco is missing.
- **`FrankaBridge.handle`:** if a topic is not one of the known ones and is in `getattr(self.backend, "extra_topics", ())`, reply `self.backend.handle_extra(topic, data)`. Unknown topics behave as today. Add an optional tick hook: `if hasattr(backend, "sim_tick"): backend.sim_tick(self)` (A6 uses it for logging; a no-op now).
- **`PandaPyBackend`:**
  - derive `error` from the panda-py/libfranka state: `robot_mode == Reflex`, or non-empty `last_motion_errors` / `current_errors`, or the controller thread having stopped unexpectedly;

  - test with a fake `panda_py` module injected into `sys.modules` (no hardware);
  - keep the `# pragma: no cover` on the real hardware calls.
- **`tools/gonogo.py`:** retry readiness by polling `get_state` for up to 10 s, instead of the fixed sleep. Add `--no-loop-gate`, which reports loop timing but doesn't gate on it (meaningless for a Python sim).
- **`panda_py_checklist.md`:** append verify items:
