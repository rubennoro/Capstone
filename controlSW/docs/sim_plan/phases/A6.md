## I-SIMSTATE message (exactly what `simlink`/`judge` read)

- **Socket:** ZMQ PUB bound on `backend.mujoco.state_endpoint` (default `tcp://127.0.0.1:5570`; normalise `localhost` → `127.0.0.1`). One part per message: `robotmq.serialize(dict)`. Subscribers use `""`.
  - Rate: `backend.mujoco.state_pub_hz` (default 100; measured ≥ 100).
  - A bind failure raises at construction with the endpoint in the message.
- **Keys:**
  - `t_mono`: `time.monotonic()` of the snapshot;
  - `qpos`, `qvel`: **the full MuJoCo vectors** (nq/nv including the fingers and the eraser free joint; A7 renders from `qpos`). StubSim sends 9 zeros, and the judge ignores both;
  - `eraser_T_base`: 4×4, eraser body in the world frame. World = robot base O; assert it once in a test;
  - `hand_gap_m`;
  - `grasped`: **physical**, both `pad_l` and `pad_r` touch the eraser with normal force ≥ 0.5 N;
  - `contacts`: `[{a, b, force_n}]`;
  - `reflex`: SimCore `error`, or None;
  - `tau_ext`: 7 values.
- **Extra keys** (allowed, ignored by the judge): `hand_mode`, `hand_grasped` (the HandSim libfranka flag), `sim_t`.
- **Contact names:** `m.geom(g).name`, or `f"{body_name}_g{g}"` for unnamed geoms. The menagerie geoms are unnamed. This rule makes `link6` / `fr3_link6`, `left_finger` / `right_finger` (pattern `finger`), `pad_l` (pattern `pad_`), `table`, `eraser`, `housing` and `cradle_*` match B9's substring patterns.
  - `force_n` = |normal| from `mj_contactForce`. Merge duplicate pairs (sum) and drop contacts < 0.1 N. At most 32 entries, largest first.
- **Production:**
  - the 1 kHz loop builds the sim-state dict every `round(rate/state_pub_hz)` wakes, under `_core_lock` (consistent data), and stores it under `_lock`;
  - a separate PUB thread sends the newest one;
  - **`get_state` keys stay unchanged** (A4 review).
  - Loop budget: A4's `p99_ms` period ≤ 2 ms and the A5 stack `period_err_ms_p99` within +0.2 ms of before A6. Measure both.

## Bridge topics

**`sim_state`:** returns the newest sim-state dict without taking `_core_lock`. Always allowed: it is read-only.

**`sim_reset`** payload (from `BridgeSim.reset` and `launcher.sim_reset`):

```
{"eraser_xy_yaw": [x, y, yaw_rad], "hand_gap_m": g}    both optional; {} = the default pose
```

The default pose is the home key's eraser pose: `robot.home_tcp.xyz_m` xy, yaw 0. An optional `object_pose` 7-vector `[x,y,z,qw,qx,qy,qz]` may be accepted additively. Nothing sends it today.

1. **Gate (bridge):** `FrankaBridge.handle` refuses `sim_reset` unless `--allow-sim-reset` (new argparse flag, stored like `allow_inject`) or `--allow-inject` is set. It raises `RuntimeError("sim_reset disabled (--allow-sim-reset)")`, which the server turns into `ok: false`. Add `allow_sim_reset=False` to `FrankaBridge.__init__` (keyword, default off). Station-less profiles are unchanged.
2. **Refused while grasping:** raise `RuntimeError("sim_reset refused: grasping (...)")` when the physical `grasped` holds or the HandSim mode is `grasping`/`holding`. `BridgeSim` maps ok:false to `SimResetRefused`, and the driver then goes home and retries.
3. **Apply under `_core_lock`:**
   - eraser free joint qpos = `[x, y, top_z + h/2 + 0.0005, quat(yaw about z)]`, its qvel = 0;
   - if `hand_gap_m`: finger joints = gap/2 each, qvel 0, `HandSim.reset(gap)` (mode `idle`, hold at that gap, `last_result` "reset");
   - `mj_forward`, then refresh the snapshots.
   - **The arm qpos, qvel, target and mode are untouched.**
   - If the eraser now penetrates anything but the table (> 1 mm), restore the previous state and refuse with the geom names.
4. **Reply** `{"ok": true, "eraser_xy_yaw": [...], "hand_gap_m": g|None, "t_mono": ...}` within **50 ms**.
   - The launcher timeout is 2.0 s and B9's `reset_timeout_s` is 3.0 s. A slow reply surfaces as `RpcTimeout`, which `BridgeSim` does **not** catch.
   - Log `sim_reset` through `bridge.log` (one line per reset).
5. `extra_topics = ("hand_cmd", "hand_state", "sim_reset", "sim_state")`. `test_backend_rt` asserts the tuple: update that assertion only.

## bridge.jsonl sim lines (`MuJoCoBackend.sim_tick(bridge)`, already called at 200 Hz)

- At `backend.mujoco.sim_log_hz` (default **25**; INTERFACES says 10, but 10 Hz quantises t_success by up to 0.1 s, which is the whole tolerance), write directly to `bridge._jsonl` when it is set. **Not** through `bridge.log`: that would print and grow `bridge.events`.

## ground_truth.py (pure: no mujoco, no zmq)

```python
KNOCK_OVER_DEG = 30.0
def evaluate(events: list[dict], criteria: dict, t_start: float, *, finger_patterns=("pad_", "tag_", "finger"),
             ignore_pairs=(("eraser", "table"),)) -> dict
def evaluate_episode(ep_dir, criteria: dict | None = None, t_start: float | None = None, **kw) -> dict | None
```

- **`events`** are `kind == "sim"` lines. The rule is the judge's rule, written independently (do not import `eval/judge.py` in the module):
  - z0 = the first sample at or after t_start; lift = z − z0;
  - success = lift ≥ `success.lift_min_m` held continuously for `hold_s` (a drop below restarts the clock);
  - decided at the first sample where that holds;
  - reflex (non-null) → n; tilt > 30° → n (knocked_over); no decision by `timeout_s` → n.
- **Returns** the `SuccessTracker.result()` keys `{success, t_success_s, grasp_t_s, max_lift_m, slip_m, slip_exceeds_tol, knocked_over, reflex, reason, lift_min_m, hold_s, timeout_s, slip_tol_m}`, plus:
  - `arm_table_contact` (non-finger contacts with the table or the eraser; same semantics as `classify_contacts`);
  - `contact_pairs`, `n_samples`, `rate_hz`, `source: "bridge.jsonl"`.
- **`evaluate_episode`:**
  - `criteria` None → `<ep_dir>/config/station_resolved.yaml` `criteria`;
  - `t_start` None → `episode_start` `t` from `<ep_dir>/events.jsonl`;
  - patterns from that station's `sim.stage3` when present.
  - It returns None when there are no sim lines (a real-arm episode).
