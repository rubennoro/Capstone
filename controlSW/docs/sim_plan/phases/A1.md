# A1: model builder (arm + Franka Hand + printed fingers + iPhone/rig + cameras + table + eraser) (Track A, wave W2)

## Goal

`franka_sim.model.build_model(station, sim=None, with_scene=True) -> SimModel` builds the MuJoCo 3.3.0 model from the B1 station, using MjSpec. The model is identical in structure for Panda and FR3.

`export_frames(sm)` returns the frames every other component relies on. The key derived results:
- the training TCP pose in the flange frame;
- the iPhone camera poses;
- **the clearance between the phone/cradle and the arm**, a hardware design input.

## Model contents (canonical names in `SimModel.names`)

1. **Arm.** Joints j1..j7 mapped to the MJCF names. Delete all stock actuators. Add `motor` actuators on the 7 arm joints with ctrlrange ±`robot.joints.tau_max_nm`, and one `motor` on tendon `split` (force range ±140 N total, from `tooling.hand.force_max_n`·2). Scale `frictionloss` by `run.sim.physics.joint_frictionloss_scale` (default 0) and damping by `damping_scale`.
2. **Sites:**
   - `flange` (the attachment_site frame, i.e. libfranka F; no rotation relative to link 7);
   - `ee` = flange·`robot.F_T_NE`·`robot.NE_T_EE` (both identity while `desk_end_effector: none`);
   - `tcp`.
3. **Printed fingers.**
   - Disable collision on the stock finger pad geoms (contype/conaffinity 0; keep visual).
   - Add one adapter box per finger body: size `tooling.finger_adapter.pad_size_m`, extended `extension_m` beyond the stock fingertip along the hand z. The inner faces are offset **outward by b/2 each**, so the pad separation equals gap + b (`tooling.width_map.b`).
   - `condim=4`, friction from the tooling.
   - A 16 mm visual tag patch on each pad's outer face (rgba black/white; collision off).
4. **TCP.**
   - Origin = midpoint between the two pad centres at the fingertip.
   - Axes: z = hand z (approach); x = along the finger closing axis; y = z × x. Training TCP: x right, y down, so the camera is on the TCP −y side.
   - The sign of x relative to the hand's finger axis is set by a new tooling key `tcp_x_along_hand: "+y" | "-y"`. It decides which side of the hand the phone sits on.
   - `F_T_TCP` = derived. If the station also has a non-placeholder `tooling.F_T_TCP`, report the deviation (mm, deg) and use the station value only when `run.sim.physics.use_station_F_T_TCP: true`.
5. **Cameras.**
   - `cam_main` world pose = TCP·inv(C_T_TCP), with OpenCV → MuJoCo axes (`R_mj = R_cv·diag(1,−1,−1)`).
   - Intrinsics from `sensor.streams.main.K` and the size: use the MjSpec camera `resolution`/`focalpixel`/`principalpixel` if available in 3.3.0, else `fovy` from fy and the size (record which in the WORKLOG).
   - `cam_uw` = cam_main·`tooling.C_main_T_C_uw` (when null, the sensor's documented placeholder: 12 mm offset, parallel axes), with the ultrawide K.
6. **Phone or rig housing.** A box of size `tooling.housing.size_m` (iPhone 16 Pro 0.0715 × 0.1496 × 0.00825) positioned so that the main lens point `tooling.housing.main_lens_in_body_m` coincides with the cam_main origin. Plus the cradle boxes `tooling.cradle_boxes` (each `{name, size_m, body_T_box relative to the housing, mass_kg}`). Masses on all of them. The sum is checked against `tooling.payload.mass_kg` minus the hand mass (report the difference; don't fail).
7. **Scene** (`with_scene`): a table box (`scene.table`) with its top at `scene.table.top_z_base_m`, and an eraser free-joint box (`scene.eraser`) at a default pose in front of the robot. Options: `implicitfast` integrator, elliptic cone, `impratio` from physics.yaml.

## API

```python
@dataclass
class SimModel:
    model: "mujoco.MjModel"; spec: "mujoco.MjSpec"; names: dict; F_T_TCP: np.ndarray; EE_T_TCP: np.ndarray; limits: dict
    robot: str; station_fingerprint: str
def build_model(station, sim: dict | None = None, with_scene: bool = True) -> SimModel
def export_frames(sm: SimModel, q=None) -> dict      # F_T_TCP, EE_T_TCP, F_T_cam_main, F_T_cam_uw, TCP_T_tag_left/right, payload
def clearance_report(sm, q6_steps=13, q7_steps=13, q_base=None) -> dict   # min distance housing/cradle <-> links 5,6,7 (+hand)
```

CLI: `python -m franka_sim model --deploy-config D --profile P | --ids robot=panda,tooling=...,sensor=...,scene=... [--robot fr3] [--out frames.json] [--clearance]` prints the frames and the clearance summary and optionally writes JSON (outside the repo).
