## API

```python
# frames.py
T_YUP_ZUP: np.ndarray                     # ARKit y-up world -> z-up world (same as sensor_rig)
def pose7_to_T(p) -> np.ndarray; def T_to_pose7(T) -> np.ndarray          # [x,y,z,qw,qx,qy,qz]
def rotvec_pos_to_T(pos, rotvec) -> np.ndarray                              # dataset (eef_pos, eef_rot_axis_angle)
def rot6d_to_R(r6) -> np.ndarray; def R_to_rot6d(R) -> np.ndarray           # first two ROWS (repo convention)
def arkit_to_zup(T_arkit) -> np.ndarray                                     # T_YUP_ZUP @ T
def yaw_about_z(T, yaw_rad) -> np.ndarray
def anchor_placement(T_grasp_zup, grasp_xyz_base, yaw_rad) -> np.ndarray    # base_T_world: maps the demo grasp TCP
                                                                            # position to grasp_xyz_base, yaw only
def relative(T_from, T_to) -> np.ndarray                                    # inv(T_from) @ T_to
# kinematics.py
class Kin:
    def __init__(self, sm, frame: str = "flange"); def fk(self, q) -> np.ndarray; def jac(self, q) -> np.ndarray  # 6x7 [v; w] world
    def ik(self, T, q0, *, q_rest=None, tol_p=1e-4, tol_r=1e-3, iters=100, damping=1e-2, limit_margin=0.02,
           w_null=0.1) -> tuple[np.ndarray, dict]          # info: ok, err_p, err_r, iters, margin_min
    def ik_multistart(self, T, seeds, **kw) -> tuple[np.ndarray, dict]       # best = ok with largest joint margin
    def contacts(self, q, *, margin=0.0, groups=("self", "table", "tooling")) -> list[dict]
    def min_distance(self, q, pairs) -> float               # mj_geomDistance (3.3) between named geom groups
    def manipulability(self, q) -> float
    def joint_margin(self, q) -> np.ndarray                 # distance to limits (rad), per joint
def check_traj(sm, T_seq, q_seed, frame="ee", *, tol_p=1e-3, tol_r=np.deg2rad(0.5), collision=True) -> dict
    # {reachable[N] bool, q[N,7], err_p[N], err_r[N], joint_margin_rad[N,7], collisions[N] (count), manip[N]}
```

- The `Kin` instance owns its own MjData and uses only `mj_kinematics` + `mj_comPos` (+ `mj_collision` for contacts). Never touch a shared MjData.
- Collision groups:
  - "self" = arm/hand geoms pairs not adjacent;
  - "table" = arm/hand/tooling vs the table;
  - "tooling" = housing/cradle vs links 1–7.
  - Excluded: the finger pads vs the eraser and the eraser vs the table.

1. **FK vs an independent numpy implementation of the Franka modified-DH (Craig) table, both arms, 200 random q within limits, flange position 1e-6 m and rotation 1e-6 rad.**
   - Craig convention: A_i = RotX(α_{i−1})·TransX(a_{i−1})·RotZ(θ_i)·TransZ(d_i).
   - a = [0, 0, 0, 0.0825, −0.0825, 0, 0.088], d = [0.333, 0, 0.316, 0, 0.384, 0, 0], α = [0, −π/2, π/2, π/2, −π/2, π/2, π/2].
   - Flange: TransZ(0.107).
   - FR3 uses the same kinematic table (check; if the menagerie FR3 differs, document by how much).
   - If there is a constant base or flange frame offset between DH and MJCF, identify it once and document it in the WORKLOG and a comment. The test then includes it.
2. Jacobian vs a finite difference of `fk` (1e-5).
3. IK round trip: 500 random reachable poses (FK of random q). ≥ 99 % `ok`, all solutions within limits, error ≤ tol. Seeds: q_rest or random.
4. Unreachable poses (2 m away) and exactly singular configurations return `ok=False` without exceptions.
5. Warm-started IK takes ≤ 1.5 ms per frame on a smooth 1000-frame trajectory (print the timing; assert ≤ 3 ms to tolerate laptop noise).
6. `contacts` finds a self-collision in a deliberately folded q, and none at home. `min_distance` is > 0 at home.
7. `frames`:
   - `arkit_to_zup` maps the ARKit +y up axis to +z;
   - equality with sensor_rig's `T_YUP_ZUP`;
   - `anchor_placement` maps the grasp position exactly and changes only yaw (the base z-axis is preserved);
   - rot6d round trip and agreement with `report.rot6d_to_R`;
   - pose7 round trip.
   - Runs in BP too, without mujoco.
8. `check_traj` on a straight-line reachable path gives all reachable, and on a path leaving the workspace it flags the right indices.
