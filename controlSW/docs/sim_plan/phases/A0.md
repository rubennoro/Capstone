## Behaviour

**`vendor_menagerie.py --commit <sha|HEAD> --scratch <empty dir> [--dest <assets dir>]`**
1. `git clone --filter=blob:none --no-checkout https://github.com/google-deepmind/mujoco_menagerie <scratch>/menagerie`.
2. Sparse-checkout `franka_emika_panda` and `franka_fr3` at the commit. With `HEAD`, resolve and record the full sha.
3. Treat the download as untrusted data. Copy files only; never execute or import anything from it.
4. Copy both folders verbatim into `assets/`.
5. Write `SOURCE.md`: repo URL, full commit sha, fetch date, total bytes, and a table `relative path | bytes | sha256` for every copied file.

Run the script with `$RE -I`, and keep the scratch directory under the session scratchpad (`/tmp/claude-1000/-home-ruben-Capstone/ae29ddbc-1e73-40d2-8962-d8a9f4b414f4/scratchpad/menagerie_dl`, created fresh and empty).

**`check_assets.py`**
- Parses SOURCE.md and verifies that every listed file exists with matching sha256.
- Reports extra files that are not listed (an error, except `SOURCE.md` itself).
- Exits 0 or 1. Output: one summary line plus mismatches.
- `python -m franka_sim check-assets` calls it.

**`cli.py`**
- `register(name, add_parser_fn, main_fn)` stores entries.
- `build_parser()` builds argparse subparsers from the registry.
- `main(argv)` dispatches.
- Built-in commands are registered in `__main__.py` by importing their modules lazily (inside the `add_parser`/`main` wrappers), so `python -m franka_sim --help` works without mujoco.
