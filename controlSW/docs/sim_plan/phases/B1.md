## station.py: API (INTERFACES I-STATION) and rules

- `load_station(spec, root=STATION_ROOT, sets=())`:
  - `spec = {"station": {...ids}, "run": {...ids}}`; any subset is allowed.
  - Loads `<root>/station/<group>/<id>.yaml` and `<root>/run/<group>/<id>.yaml`.
  - Validates, then resolves `${group.path}` (after all groups load; detect cycles).
  - Applies `sets` (`"group.path=yamlvalue"`).
  - Returns a frozen `Station`.
- **Validation (`validate_group(group, d) -> list[str]`):**
  - `schema` and `id` present and matching the file;
  - numeric leaves must carry a unit suffix unless they are under an allow-listed key (design doc list); make the allow-list a module constant;
  - every leaf resolves to a provenance entry (prefix-inherited, `""` = whole file);
  - `status` must be in the allowed set;
  - `critical` paths must exist;
  - tooling `sensor_compat` must contain the loaded sensor id.
- **Errors:** a single `StationError` listing all problems.
- **`Station` methods:**
  - `get(path, default)`, `prov(path)`;
  - `placeholders(critical_only)` returns (path, Prov) for status placeholder|hw;
  - `fingerprint()` = sha256 of canonical JSON of the groups, first 16 hex chars;
  - `to_yaml()` holds ids, overrides, groups and provenance;
  - `bridge_fragment()`, `controller_fragment()`, `task_args()`, `camera_config(endpoint, logger_endpoint)`, `sender_config()`, as in design_track_b.md.
- **`station_from_deploy_cfg(cfg)`:** returns None without a `station` key; otherwise `load_station({"station": cfg["station"], "run": cfg.get("run", {})}, sets=cfg.get("station_set", []))`.
- **CLI:** `python -m franka_deploy.station validate [--root R] [--all | --spec station.robot=panda ...]` validates every file (`--all`) or a combination, then prints placeholders and the fingerprint. Exits 0 or 1. Reviewers use this.
