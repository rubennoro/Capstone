# A7: Renderer (+0.5 px fix), camera-view check vs real demo frames, policy image gap, render sender (Track A, wave W8)

## Goal

1. **`Renderer`** produces exactly the images each sensor puts on the wire, from the full sim `qpos`:
   - **iPhone (v1):** main + ultrawide, BGR 960×720, at the iPhone deploy K (main f 703.1714, c (476.3752, 361.3600); UW f 388.5231, c (480.6903, 359.7618));
   - **rig (v2):** the rig's *virtual-iPhone* images. The rig remaps both physical cameras to the same virtual K at 960×720. Since commit 290acfd the physical ultrawide is an Arducam B0179 175° fisheye.
2. **`camera-check`** measures how close renders are to the real training frames:
   - tag reprojection, the hand-body mask and overlays;
   - **image MAE / SSIM against the zarr frames at matched poses**.
3. **`camera-gap`** feeds rendered vs real images to the policy and reports the action gap, as Stage 2b does. The B8 review showed that the policy is very sensitive to image differences: JPEG q90 alone gives p50 5.5 / p95 19.7 mm at k15.
4. **`render_sender`** is the `image_source: render` sender that B9's launcher already starts.

Start after A6 is committed: the sender subscribes to A6's PUB.

## Renderer (`render.py`, I-RENDER)

```python
class Renderer:
    def __init__(self, sm, station, *, streams=("main", "ultrawide"), sizes: dict | None = None, rig: str | None = None,
                 lighting: dict | None = None)
    def render(self, qpos_full) -> dict            # {"main": BGR uint8 (H, W, 3), "ultrawide": ...}; H, W = the stream size
    def segmentation(self, qpos_full) -> dict      # per stream: int32 geom id per pixel (-1 = background)
    def geom_groups(self) -> dict                  # {"fingers": [...], "tags": [...], "hand_body": [...], "tooling": [...], "scene": [...]}
    def close(self)
```

- **The cameras are the model's `cam_main` / `cam_uw`** (station sensor `streams.*.K`, width/height). The rig sensor `rig1_wifi` carries the *virtual* K, so the same code serves v2.
  - Raise `model.vis.global_.offwidth/offheight` when a size exceeds them.
  - Use a private `MjData` and kinematics only (`mj_kinematics` + `mj_camlight`): rendering never steps physics.
  - RGB → BGR.
- **Half-pixel fix** (A1 finding 1) in `model._set_cam_intrinsics`. Tests: rendered centroids of small markers at ≥ 4 off-centre points per stream vs `cv2.projectPoints` with K, |Δ| ≤ 0.15 px. A1 measured −0.5 px. Add the markers in the test via `sm.spec` + recompile, not in model.py.
- **Other intrinsics** (camera-check renders at 1920×1440 / 640×480 training K): build a second `SimModel` from the station with `sensor.streams.<s>.K/width_px/height_px` overridden (a groups copy or station sets). Do not write `cam_intrinsic` at run time.
- **`rig=<rig yaml>` (fidelity mode, optional per call):**
  - render the virtual camera, `RigConfig.inverse_remap(name)` → the physical image, then `RigConfig.remap(name, (960, 720))` back, as `obs_equivalence.rig_images` does through `RigFrameSource`;
  - this reproduces the rig's resampling blur and any uncovered border of the B0179 fisheye (equidistant f 670 px, θ_max 89°);
  - report `coverage_report()` for the b0179 yaml. It is expected to be 1.0: commit 290acfd says coverage stays 1.0 for f 1.30–1.69 mm.
  - The plain render (no `rig`) is the default for v2: the wire format is the virtual image either way.
- **Lighting and colours** are kwargs with documented defaults, not hardcoded in several places. If a station/run group is wanted, list it for the orchestrator (`run/sim/render.yaml` is Track B).
- **Speed:** measure render + JPEG of both streams. Target p95 ≤ 25 ms per pair at 960×720 with EGL. If not met, report it and render the UW at a lower internal size then resize (flagged in the ready file).

## camera-check (`python -m franka_sim camera-check`, RE)

```
MUJOCO_GL=egl $RE -m franka_sim camera-check --profile sim-iphone [--robot panda|fr3] [--set k=v ...] \
    --raw /home/ruben/Capstone/data/raw/2026-10-01 --zarr $ZARR --stage1 controlSW/docs/sim_plan/results/stage1/panda_ext0.1_my_stage1.json.gz \
    --episodes 5 --frames-per-episode 40 --out $S/a7/camcheck_<tooling>
```

Run it at the station tooling **and** at `--set tooling.finger_adapter.extension_m=0.1 tooling.tcp_x_along_hand=-y` (the Stage 1 candidate). Outputs go to `--out` in scratch: `camera_check.json` + ≤ 30 PNGs (≤ 1 MB each) + `renders.npz`.

1. **Intrinsics:** per episode, its JSON K (`IphoneEpisode.K_main/K_uw`) → which `training_intrinsics_variants` entry. Render at that training K and size (main 1920×1440, UW 640×480).
2. **Tags:**
   - detect the finger tags on real UW frames with cv2.aruco (`fdcal.width.load_aruco()` dict + sizes; both cv2 aruco APIs as `sensor_rig/record/tagcheck.py`);
   - set the sim gap from that frame's measured width (zarr `gripper_right_gripper_width` → `WidthMap.gap`);
   - project the sim tag centres (`export_frames` `TCP_T_tag_*` + the UW camera);
   - report per-tag pixel error p50/p95/max per episode.
   - Also fit and report (not write) the UW extrinsic correction `C_main_T_C_uw` that minimises the error: the station value is null and `UW_PLACEHOLDER` is a guess.
3. **Hand-body mask:** the fraction of each stream covered by `hand_body` + `tooling` geoms (the real iPhUMI frames show neither), plus the pixel bbox. Overlays at open/mid/closed widths.
4. **Image similarity at matched poses:**
   - for ≤ 40 frames per demo (spread over approach, grasp and lift), map the demo TCP into the base frame with `base_T_world[name]` (poses via `stage1_replay.load_demos` + `prepare_demo`, so they are in the same frame as stage1);
   - IK the arm (`Kin(sm, "tcp")`; skip frames whose IK fails and count them);
   - put the eraser at `grasp_xyz_base` with the yaw of the grasp-frame TCP before `grasp_index`, and between the pads after it;
   - render the **deploy path** (960×720 at the deploy K), and also for the rig sensor with `rig=b0179`;
   - turn both render and real into 224 with `get_image_transform_with_border(in_res, (224, 224))`. Load it by file path if the package import pulls torch into RE; never edit it.
   - Compare with the zarr frame (`DemoZarr.main_image` / `uw_image`, BP-readable; or read the zarr in RE if imagecodecs is present, else export the needed frames once in BP to `$S/a7/zarr_frames.npz`).
   - Report MAE (0–255) and SSIM (grey, 11×11 Gaussian σ 1.5, standard constants; numpy + cv2, since skimage is absent; tested against SSIM(x, x) = 1) for: **full frame**; **gripper ROI** (segmentation of fingers + pads + tags, resized to 224); and **scene only**.
   - Noise floors: real vs JPEG q90 960×720 round trip; real vs the next real frame.
   - Save the 224 renders (uint8) for every frame `deploy_obs` reads for the chosen queries (main fi−3, fi; UW per `DemoZarr.uw_index`) to `renders.npz` with `(demo, frame, stream)` keys.

## render_sender (`franka_sim/senders/render_sender.py`)

`python -m franka_sim.senders.render_sender --config sender.yaml --state-endpoint E --station station_resolved.yaml --host H --ports P[,P] --protocol v1|v2 --fps F [--link link.yaml] --truth T --ready-file R [--loop] [--max-s S] [--connect-timeout 15]`

- **Accept every argument `launcher.sender_command()` passes.** `--loop` is accepted and is a no-op: the renderer runs until killed.
- **Setup:**
  - `load_station` from the `--station` yaml;
  - `build_model(station, physics)` with the same physics/run sim as the backend;
  - `Renderer`;
  - SUB to the state endpoint with `judge.StateSubscriber` semantics (subscribe "", newest message wins).
- **Each tick at `--fps`:** take the newest state, and if it is older than 0.2 s, skip and count `stale_states`. Render `qpos`, then JPEG at `streams.*.jpeg_quality` from `--config` (0–1 → ×100).
  - **v1:** no stamps. Send each stream at `state.t_mono + clock.latency_s[stream]` from `--config`, so the receiver's arrival − latency recovers the state time, as `iphone_replay_sender` models the app. The launcher passes no `--capture-latency-s` for render.
  - **v2:** `send_v2(main, uw, t_state, t_state, seq, w, h)` immediately. The capture stamp = the state time, and the hello K = the station K.
  - Truth lines through `StreamClient(truth_path=...)` hold the state time.
- **Ready file** (atomic, like the replay sender): `{sender: "render_sender", protocol, fps, size, K_main, K_uw, state_endpoint, start_now_ns, render_ms_p95}`, written after the first frame was sent.
- **Exit 0 on SIGINT/SIGTERM.** A non-zero exit means the launcher's `sender_died` (an abort in B9).
