## Caveats the user should hear
- **A. Optimum may lie beyond the grid.** The Panda placement gx = 0.70 is the x grid edge. The scene box allows x up to 0.80. The 43/45 result is not shown to be the optimum in x, but a wider grid could only add demos.
- **B. Safety cone is not part of feasibility.** The flange exceeds the 60 deg bridge cone in 37/45 demos (mean 24 % of frames, max 86 deg) in every row. `SafetyFilter` would clamp these on hardware, so the real success rate could be lower. Raising the cone value, or gating it, is the user's decision (scene yaml line 11).
- **C. Other limits.** Clamp fraction 8.6 % (slowdown 1.00, so no time loss). `peak_dq` is within limits for only 19/43 (FR3) and 36/43 (Panda) feasible demos. Pads dip below the table at the placeholder h. All are informational.
- **D. Not run on hardware.** The finger extension (+10 cm) and the phone side (-y) still need the user's confirmation. Stock-length fingers are infeasible (8-40/45).
