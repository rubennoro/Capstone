# B9: Stage 3 closed loop (judge, between-episode reset, episode driver), sweeps, summary comparison; sim-iphone/sim-rig finalized (Track B, wave W7/W9)

## Goal

`python -m franka_sim eval --stage 3` runs a policy closed loop on the full stack:
- it runs N episodes × M eraser poses;
- a **judge** decides success from the sim state and writes `y`/`n` to the task's command file;
- between episodes it does `r`, then `sim_reset` to the next pose, then `c`.

`--sweep` runs a cartesian grid of Stage 3 (or any stage) runs, with resume. `summary.html` compares the runs.

The closed loop with MuJoCo needs **A5** (hand), **A6** (scene, `sim_reset`, state PUB, ground truth) and **A7** (render sender). Build in two parts:
- **Part 1 (now):** pure judge + criteria + sweeps + summary, and Stage 3 end to end on `sim-iphone-fake` (FakeBackend, fake gripper, video replay) against an in-process **stub sim** that implements the A6 interfaces below.
- **Part 2 (after A6/A7):** switch to the real interfaces; run the PLAN acceptance on `sim-iphone`/`sim-rig`.

Stage 3 measures plumbing, safety and timing. Success is informational (rendered or stub images); the report says so.

## Stub interfaces (code against these; A6/A7 must match them; the orchestrator copies them into the A6/A7 specs)

```python
class SimHandle(Protocol):                         # simlink.py
    state_endpoint: str                            # the PUB the judge subscribes to
    def reset(self, eraser_xy_yaw: tuple[float, float, float], hand_gap_m: float | None = None) -> dict  # raises SimResetRefused
    def latest(self) -> dict | None                # newest I-SIMSTATE dict
    def close(self)
class BridgeSim(SimHandle):   # A6: BridgeClient(bridge, reset_timeout_s).request("sim_reset", {"eraser_xy_yaw": [x, y, yaw_rad],
                              #   "hand_gap_m": g}); ok:false -> SimResetRefused (e.g. grasping); latest() = "sim_state" topic
class StubSim(SimHandle):     # now: a thread PUBs I-SIMSTATE at 100 Hz on state_endpoint; scripted eraser per scenario
```

- **I-SIMSTATE message:**
  - one ZMQ part, `robotmq.serialize(dict)`; subscribe `""`;
  - keys `{t_mono, qpos, qvel, eraser_T_base (4x4), hand_gap_m, grasped, contacts: [{a, b, force_n}], reflex: str|None, tau_ext}`;
  - `contacts` uses MuJoCo geom names.
- **StubSim scenarios** (relative to the episode start the driver signals via `stub.on_episode_start(t)`):
  - `lift_success` (+6 cm at 3 s, held);
  - `no_lift`;
  - `lift_drop` (lift, drop at +1 s);
  - `knock_over` (tilt 45°);
  - `collision` (an `link6`↔`table` contact at 2 s);
  - `reflex` (the driver additionally sends bridge `inject_reflex` at 2 s; FakeBackend supports it with `allow_inject`).
- **Endpoints with a port offset o:**
  - state `tcp://127.0.0.1:{5570+o}` (deploy key `sim_state_endpoint`);
  - bridge `5565+o`;
  - in sim profiles, `tooling.hand.endpoint=tcp://127.0.0.1:{5565+o}` (sim-iphone hardcodes 5565 in `station_set`).
- **A7:** I-RENDER; the render sender is started by `launcher.sender_command()`. B9 adds `--state-endpoint <sim_state_endpoint> --station <session>/config/station_resolved.yaml` to that command for `image_source == render`; A7's `render_sender` must accept both.

## judge.py

```python
class SuccessTracker:                       # pure: no I/O, no zmq
    def __init__(self, success: dict, t_start: float, z0: float | None = None)
    def update(self, s: dict) -> str | None # "y" on success (lift >= lift_min_m held >= hold_s), "n" on timeout_s / reflex / knock-over
    def result(self) -> dict                # {success, t_success_s, grasp_t_s, max_lift_m, slip_m, knocked_over, reflex, reason}
def classify_contacts(contacts, finger_patterns, ignore_pairs) -> list   # non-finger collisions (arm/hand/tooling vs table/eraser)
class Judge(threading.Thread):             # StateSubscriber -> tracker -> appends "y"/"n" to <session>/commands.txt once
```

- **Lift** = eraser z − z at episode start. **Slip** = the largest drop below the running maximum while `grasped`, reported against `slip_tol_m` (no early stop).
- **Knock-over** = tilt > 30° (as A6's ground truth). **Reflex** = `reflex` non-null.
- **CLI:** `python -m franka_sim.eval.judge --state-endpoint E --commands FILE --deploy-config D --profile P [--set ...]`, for manual runs.

## stage3.py (episode driver)

1. **Derive a deploy yaml as Stage 2b does** (refactor `stage2b.derive_deploy`'s port-offset block into a shared helper; 2b behaviour unchanged):
   - `sim_state_endpoint`, the hand endpoint and `work_root` in the run dir;
   - `--set` passthrough.
   - Launch `python -m franka_deploy run --config <derived> --profile P --no-tty --script "<budget_s>:q"`. The script is only a backstop; the driver normally ends the run.
2. **Wait** for the newest `work/session_*` and `<session>/task_ready.json`.
3. **Per pose p, episode e:**
   1. `sim.reset(pose)`; on SimResetRefused, write `r`, wait, retry once.
   2. Sleep `settle_s`. Write `c` to `<session>/commands.txt`.
   3. Wait for `episode_start` in `logs/task.log` (`[franka_task] episode_start`); on `refused_start`, retry up to `start_retries_n`.
   4. Start the Judge. It writes `y`/`n`.
   5. Wait for `episode_finalized`; write `sim_truth.json` (`tracker.result()` + pose + scenario) into the episode dir.
   6. On a reflex: bridge `recover` (BridgeClient), then `r`. If the next `c` is refused `start_retries_n` times, stop: INCOMPLETE with the reason.
   7. Write `r` and wait until bridge `get_state` O_T_EE is within `home.max_dist_m` of home, or `home_timeout_s`.
4. **End:** write `q` and wait for the launcher exit. `sender_died` or a launcher FAIL → INCOMPLETE with the reason. A reflex or collision is a FAIL, not INCOMPLETE.
5. **Per-episode metrics** (episode dir `task/episodes/*/*/*/episode_*`):
   - **from `label.json` / `sim_truth.json`:** label and success;
   - **from `controller_trace.npz`:**
     - tracking = ‖`safe_target`[:3] − `fk`[:3]‖ (mm);
     - gripper lag = action steps (1/`agent_update_freq_hz` = 50 ms) until |`width_measured` − `width_commanded`| < 2 mm after each commanded change > 4 mm. Exclude intervals where the sim says `grasped`.
   - **from the tap:** `info_inference_s`; obs motion = ‖fk(`info_main_ts`[-1]) − fk(`info_state_ts`[-1])‖ (mm), with fk interpolated from the trace.
   - **from the logs:**
     - reflexes = `bridge.jsonl` `kind == "reflex"` lines;
     - collisions = `classify_contacts` over the judge's stream;
     - `stale_image` from the task counters;
     - receiver age p95 from `logs/camera_stats.json`.
6. **Metrics:**
   - success_rate + Wilson 95 % CI (`franka_deploy.eval.metrics.wilson`);
   - `n_episodes`, labels, holds, slip;
   - `sim_source` (`stub`|`mujoco`), `image_source`;
   - wall-clock metrics are listed under `timing`.
   - Rows: one per episode. Gates from `criteria.stage3`.

## Sweeps (`sweeps.py`), summary

- **Spec** (`run/sweeps/*.yaml`): `axes` is a list of `{group: <run|station group>, ids: [...]}` or `{set: <path>, values: [...]}`, plus `stage`, `max_runs`, `seed`, `n_episodes`, `resume`.
  - Expansion order is deterministic, row-major over the axes.
  - Point i gets `seed + i`.
  - Each point → `runner.resolve(args, run_overrides, extra_sets)`. Extend `resolve`; current callers are unchanged.
  - `OUT/sweep_index.json` maps point → run dir.
- **`--sweep` takes an id or a path.**
  - **Resume:** a point whose run dir holds a `report.json` with a verdict other than INCOMPLETE is skipped.
  - `max_runs` caps the number of new runs.
  - The process may be killed between points.
- **Sweep files:**
  - `block_raise_default.yaml`: link × policy × `criteria.limits.v_max_m_s: [0.25, 0.5]` × `sensor.task.camera_latency_s: [0.05, 0.1, 0.15]`; the PLAN robot and sensor axes are listed but commented out;
  - `block_raise_smoke.yaml`: link {ideal, wifi_good} × policy {fake, demo_replay}, stage 3, 1 episode × 1 pose.
- **`report.write_summary`** keeps today's rows and adds a comparison table: one column per run with the sweep axis values as headers; rows = verdict, success_rate (CI) and each gate value with pass colouring. Inline CSS, no scripts.
