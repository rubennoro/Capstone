## Findings
1. **(blocker, kit import A9e + user measurement) The kit's tag positions do not match the training gripper.**
   kit.yaml:28/44 (`centre` +-0.06 m from the engraved outline, provenance :71) puts the tags 23 mm too far inward per side,
   and about 8 mm too close in depth. Either the iPhUMI gripper used for firstreal is not this Onshape UMI assembly (holder
   spacing or sticker position), or the sticker isn't on the engraved outline. Needed: on the real gripper, measure the
   tag-centre-to-gripping-face distance and the closed tag separation (data says ~88 mm), and fix the kit from CAD or those
   measurements. Do not fit it silently; if fitted, mark the provenance `fitted`, as the box tags are. Then rerun P1.
2. **(minor, camera_check.py:510-515) Kit mode with tag ids outside TAG_IDS falls back to image order silently.** A kit with
   only one tag placed would raise KeyError (`ids[f"tag_{s}"]`). In kit mode, raise NoTags-style (rc 2) unless the ids are
   exactly {0, 1}. Keep image order for box mode.
3. **(minor, model.py:926-944 + tooling YAML:56/93, both YAMLs) The payload report hides the kit mass.** `difference_kg` excludes
   `finger_kit_mass_kg`. Add a kit-inclusive difference (or warn when |configured - true| > 0.1 kg). When the kit becomes the
   default, raise the `payload.mass_kg` placeholder (~1.27 kg at L 0.008, solid density; weigh the printed parts, P6).
4. **(major, Stage 1b, A9c/A8 owner) Kit 1b regression: 9/45 lifts vs 36/45, reflex 40/45.** It is finger-dependent: same
   design pipeline, the scripted pick is OK. Next: log the contact pairs at reflex time in 1b. Try a tip height of 7-10 mm and
   a tooling-clearance rule for wide tips, before any kit default.
5. (minor, doc) finger_model.md:268: drop "updated by hand ... (regenerate to confirm)" (confirmed identical). Section 7
   :251-254: P0/P2 done, P1/P3 failed with these numbers. The `kit.yaml` header comment "min adapter ~0.008 m" is confirmed
   (+0.61 mm hull clearance at 0.008; the limit is ~0.0074).
