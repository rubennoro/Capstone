## Changes

1. **`camera.kind`:** `rig_local` (default when absent; today's command, unchanged) | `wireless`.
   - `wireless` writes `session/config/camera.yaml` from `station.camera_config(endpoint, logger_endpoint)` and starts `[realenv, -u, -m, franka_deploy.peripherals.wireless_camera, --config, …]`, with `stats_path=<session>/logs/camera_stats.json` and, in sim, `truth_path=<session>/logs/camera_truth.jsonl`.
   - `check_config` accepts `camera.kind`; the old `camera.config in (wrist_right, wrist_mock)` rule applies only to `rig_local`.
2. **Sender child (sim profiles only), started after the receiver and before the camera readiness wait:**
   - `run.sim.image_source == video_replay` → `franka_deploy.stream.iphone_replay_sender --episode <run.sim episode> --protocol <sensor protocol v1|v2> --fps <sensor main physical fps> --link <run.link yaml> --truth <session>/logs/sender_truth.jsonl --ready-file <session>/sender_ready.json --loop`, against 127.0.0.1 and the sensor ports.
     - The episode is resolved from `run/sim/video_replay.yaml` (`episode` = a raw iPhone episode dir name, or an index into `data/raw/2026-10-01` firstreal demos; document which).
     - `station_set ["sensor.transport.bind_host=127.0.0.1"]` in sim profiles.
   - `rig_raw_replay` → reserved for B7 (`franka_deploy.stream.rig_replay_sender`); `check_config` reports "not available yet" until B7 adds it.
   - `render` → reserved for A7/B8 (`franka_sim.senders.render_sender`).
   - `TEARDOWN_ORDER = ("task", "controller", "sender", "camera", "inference", "spacemouse", "hand", "bridge")`.
3. **Preflight additions:**
   - `ports_free` includes the receiver ports, the sim-state port 5570 for mujoco backends, and the hand port 5566 when a hand child runs.
   - `websocket_available` (`import simple_websocket` in python.realenv).
   - After the camera is up, `wireless_health_ok(stats_path)`: within 5 s the transport has **upgraded to websocket**; `fps_in ≥ 0.9·physical_fps` per stream; `age_s p95 ≤ health.max_age_s`; no reconnects during the check window; no size mismatches. FAIL with a clear message otherwise (e.g. "transport stuck on polling: install simple-websocket").
   - `clock_ok` for v2: ping RTT min < 20 ms and offset stable within 2 ms over 3 s.
   - `hello_problems` (v2): warning only. The replay sends each episode's own K, so a K mismatch with the sensor yaml is expected in sim; FAIL only in real mode.
4. **Task image-age guard:**
   - `run_task --max-image-age-s` (default None = today);
   - `FrankaPromptTask(max_image_age_s=None)`;
   - in `get_observations`, after frame selection: if set and `time.monotonic() − main_ts[-1] > max_image_age_s`, raise `FrameSelectionError("image … ms old")`, which reuses the existing retry path; counter `stale_image` in the task summary.
   - The launcher passes it from `station.task_args()` (sensor `task.max_image_age_s`) when a station exists.
